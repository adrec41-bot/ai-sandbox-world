# AI Sandbox World

Кооперативная 3D-песочница на 5–10 игроков. Каждый игрок через своего ИИ-агента (по MCP) создаёт в общем мире постройки, объекты и физику, а потом все вместе в нём играют.

## План

1. **Прототип мира** (готово): открытая местность с рекой, лесом и деревней, персонаж с видом от третьего лица, единый мультяшный стиль.
2. **Мультиплеер:** выделенный сервер на 5–10 игроков, синхронизация и сохранение мира.
3. **MCP для ИИ-агентов:** генерация построек и объектов по промту. Стиль держится за счёт скрытого базового промта, общего тун-шейдера и приведения цветов к палитре мира.
4. **Сборка и тест:** установщик для Windows, первая сессия с друзьями.

## Как запустить

1. Скачайте [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (обычная версия, не .NET).
2. В Godot нажмите **Import** и выберите файл `project.godot` из этой папки.
3. Нажмите **F5**.

Управление: WASD ходить, Shift бег, Пробел прыжок, клик мышью захватить камеру, колесо зум, Esc отпустить мышь.

## Устройство

- `scripts/world.gd` строит мир процедурно: рельеф, реку, лес, деревню, свет и интерфейс. Внешние ассеты не нужны.
- `scripts/player.gd` отвечает за персонажа и камеру.
- `shaders/toon.gdshader` и `shaders/outline.gdshader` задают общий стиль. Через них рисуется любой объект мира, в том числе будущие сгенерированные ИИ.
- Рендерер GL Compatibility выбран ради стабильности: игра пойдёт даже на слабых видеокартах.
