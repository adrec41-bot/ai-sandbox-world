# AI Sandbox World

Кооперативная 3D-песочница на 5–10 игроков. Каждый игрок через своего ИИ-агента (по MCP) создаёт в общем мире постройки, объекты и физику, а потом все вместе в нём играют.

## План

1. **Прототип мира** (готово): персонаж с видом от третьего лица, рисованный стиль старой диснеевской анимации. Сейчас мир ровный и пустой, деревня, лес и река отключены (скрипты остались на будущее).
2. **Мультиплеер:** выделенный сервер на 5–10 игроков, синхронизация и сохранение мира.
3. **ИИ-строитель** (готово, первая версия): пишешь просьбу в поле внизу экрана, подключённый по MCP агент строит объект. Стиль держится за счёт скрытого базового промта, общего тун-шейдера и приведения цветов к палитре мира.
4. **Сборка и тест:** установщик для Windows, первая сессия с друзьями.

## Как запустить

1. Скачайте [Godot 4.3](https://godotengine.org/download/archive/4.3-stable/) (обычная версия, не .NET).
2. В Godot нажмите **Import** и выберите файл `project.godot` из этой папки.
3. Нажмите **F5**.

Управление: WASD ходить, Shift бег, Пробел прыжок, клик мышью захватить камеру, колесо зум, Esc отпустить мышь.

## ИИ-строитель

Мир пока ровный и пустой: всё в нём создают сами игроки.

Внизу по центру поле ввода на две строки. Нажми **Enter**, напиши, что построить («мельница с лопастями», «куча бочек, которые можно толкать»), и снова Enter (Shift+Enter переносит строку). Просьба уходит твоему ИИ-агенту по MCP, он придумывает объект, и тот попадает в **инвентарь** (8 слотов над полем). Ответы агента видны над инвентарём.

Инвентарь: **1–8** выбрать слот, **F** поставить предмет перед собой (предмет остаётся в инвентаре, его можно ставить много раз), **G** подобрать объект перед собой, **X** удалить предмет из инвентаря.

Агента нужно подключить один раз: нажми **F2**, выбери свою программу (Claude Code, Cursor, VS Code, Claude Desktop) и вставь скопированное туда, куда написано. Игра сама работает как MCP-сервер на `http://127.0.0.1:7778/mcp`, ставить ничего не нужно (кроме Node.js для Claude Desktop). Ключ API не нужен: объекты придумывает модель самого агента.

Как это работает: MCP-запросы всегда идут от агента к игре, поэтому агент вызывает инструмент `wait_for_player_request`, и игра держит этот запрос открытым, пока игрок не напишет просьбу. Агент строит её через `place_object` и снова ждёт. Пока под полем горит «● ИИ-агент на связи», агент слушает игру.

К каждой просьбе добавляется общий скрытый промт стиля (`ai/style_guide.md`), а игра рисует всё общим шейдером и приводит цвета к палитре, поэтому объекты от разных игроков не выбиваются из мира. Созданное сохраняется между запусками.

Для продвинутых: отдельный [mcp-server](mcp-server/README.md) на Node.js умеет сам генерировать объекты через Claude API.

## Стиль

Мир выглядит как старая рисованная диснеевская анимация в сепии. Почти весь стиль задаёт финальный фильтр кадра `shaders/post.gdshader`: чернильные контуры по глубине с «дрожанием» руки, штриховка в тенях, дымка вдали, бумажная фактура, мягкое свечение окон и виньетка. Он действует на всё, что видно, поэтому любой объект, в том числе сгенерированный ИИ, автоматически попадает в стиль мира.

## Устройство

- `scripts/world.gd` собирает мир: ровная равнина с невидимыми стенами по краю, свет, игрок, интерфейс.
- `scripts/style.gd` хранит тональную палитру, материалы и простые меши. Через него строится всё в мире.
- Сейчас не используются: `scripts/nature.gd`: деревья трёх видов, трава, кусты, цветы, камыш, камни.
- `scripts/village.gd`: фахверковые дома с дымом из труб, мельница, причал с лодкой, фонари, костёр, мост.
- `scripts/scenery.gd`: дальние горы, облака, летающий остров с башней и водопадом.
- `scripts/player.gd` и `scripts/pet.gd`: персонаж с камерой и питомец-спутник.
- `scripts/agent_bridge.gd`: очередь просьб игрока, инвентарь, команды мира для ИИ, сохранение в `user://world.json`, WebSocket на порту 7777 для `mcp-server`.
- `scripts/mcp_http.gd`: MCP-сервер внутри игры на порту 7778.
- `scripts/ai_panel.gd`: поле ввода просьб, слоты инвентаря и панель подключения агента (F2).
- `scripts/ai_guide.gd`, `ai/style_guide.md`, `ai/builder_prompt.md`: скрытый промт стиля, формат описания объектов и инструкция для агента-строителя.
- `scripts/object_builder.gd`: строит объект из описания агента через общий стиль и палитру.
- `mcp-server/`: MCP-сервер для ИИ-агентов, см. его README.
- `scripts/hud.gd`: интерфейс (задание, мини-карта, полоски, панель предметов), нарисованный линиями.
- `shaders/toon.gdshader` и `shaders/outline.gdshader`: ступенчатое освещение, контровой свет, покачивание на ветру и контуры объектов.
- Рендерер GL Compatibility выбран ради стабильности: игра пойдёт даже на слабых видеокартах. Внешние ассеты не нужны.
