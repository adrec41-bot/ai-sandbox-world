# MCP-сервер AI Sandbox World

> Для обычной игры этот сервер не нужен: игра сама работает как MCP-сервер, а подключение настраивается кнопкой в игре (F2). Отдельный сервер нужен, если хочется, чтобы объекты по промту генерировал Claude через API, а не модель самого агента.

Через этот сервер любой ИИ-агент с поддержкой [MCP](https://modelcontextprotocol.io) (Claude Desktop, Claude Code, Cursor, VS Code и другие) создаёт объекты в мире игры по обычному текстовому описанию: «кривая деревянная мельница», «куча бочек у причала», «каменный колодец с навесом».

## Как это устроено

```
ИИ-агент ──MCP──▶ mcp-server ──WebSocket──▶ игра (Godot) ── строит объект через общий шейдер и палитру
```

1. Агент вызывает `generate_object` с промтом игрока.
2. Сервер добавляет к промту **скрытый базовый промт стиля** (`ai/style_guide.md`, общий с игрой) и генерирует описание объекта: формы, размеры, цвета палитры, физику.
3. Описание проверяется и попадает в инвентарь игрока. Когда игрок ставит предмет (F), игра строит его через `scripts/object_builder.gd`: все детали рисуются тун-шейдером мира, а любые цвета приводятся к его палитре, поэтому объекты от разных игроков выглядят единым миром.
4. Инвентарь и поставленные объекты сохраняются в `user://world.json`.

Геометрия генерируется свободно, а не собирается из готовых деталей: агент описывает форму из примитивов, тел вращения (`lathe`, профиль вращается вокруг оси) и выдавленных контуров (`extrude`, любой многоугольник).

### Кто генерирует описание

Сервер пробует по порядку:

1. **Claude через API**, если задан `ANTHROPIC_API_KEY`. По умолчанию модель `claude-opus-5-5`, можно сменить через `ANTHROPIC_MODEL`. Включён серверный запасной вариант на случай отказа модели (`fallbacks: "default"`).
2. **Модель самого агента** через MCP sampling, если клиент это умеет. Ключ API тогда не нужен.
3. Если нет ни того ни другого, `generate_object` возвращает агенту руководство по стилю и формат описания. Агент сам пишет описание и вызывает `create_object`. Так работает любой агент, даже без настроек.

## Инструменты

| Инструмент | Что делает |
|---|---|
| `wait_for_player_request` | Ждёт, пока игрок напишет просьбу, и возвращает её с `request_id`, видом, размером, площадкой и тем, что изменить; сюда же приходят ответы на `ask_player` |
| `reply_to_player` | Показывает игроку короткий ответ на карточке просьбы |
| `ask_player` | Задаёт игроку вопрос с 2–4 вариантами ответа кнопками |
| `report_progress` | Пишет на карточке просьбы, что агент сейчас делает |
| `get_style_guide` | Руководство по стилю и формат описания объекта |
| `get_world_info` | Размер мира в шипах и метрах, где стоит игрок и куда смотрит, отмеченная площадка, цвета, физика |
| `get_area` | Что уже стоит на площадке или прямоугольнике и какой оно высоты |
| `generate_object` | Создаёт объект по промту и кладёт его в инвентарь игрока |
| `create_object` | Кладёт в инвентарь игрока объект из кирпичей по описанию агента; с площадкой или `place: true` сразу ставит его в мир |
| `update_object` | Меняет поставленный объект или предмет инвентаря (игрок может отменить Ctrl+Z) |
| `get_object_spec` | Полное описание объекта или предмета, чтобы его изменить |
| `set_world_physics` | Меняет физику мира игрока: гравитацию, скорость игроков, высоту прыжка, скорость времени |
| `list_objects` | Объекты, поставленные в мир: кто, что и где |
| `move_object` | Переносит или поворачивает объект |
| `remove_object` | Удаляет объект |

Ресурс `style://guide` содержит базовый промт стиля и формат описания, включая механики (`spec.mechanics`: транспорт, снаряжение, интерактивные предметы, анимации деталей).

## Установка

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
cd mcp-server
npm install
```

Запустите игру в Godot (F5): она откроет мост для агентов на `ws://127.0.0.1:7777`. Порт меняется переменной окружения `AI_SANDBOX_PORT` у игры и `WORLD_URL` у сервера.

### Claude Desktop

В `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "ai-sandbox-world": {
      "command": "node",
      "args": ["C:/путь/к/ai-sandbox-world/mcp-server/src/index.js"],
      "env": { "PLAYER_NAME": "Хетаг" }
    }
  }
}
```

### Claude Code

```bash
claude mcp add ai-sandbox-world -e PLAYER_NAME=Хетаг -- node /путь/к/ai-sandbox-world/mcp-server/src/index.js
```

### Другие агенты по HTTP

```bash
node src/index.js --http 8787
```

Адрес для агента: `http://127.0.0.1:8787/mcp` (Streamable HTTP). По умолчанию сервер слушает только этот компьютер; `HOST=0.0.0.0` открывает его в сеть, но авторизации пока нет, поэтому делайте так только в доверенной сети.

## Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `WORLD_URL` | `ws://127.0.0.1:7777` | Адрес мира. Для мультиплеера здесь будет адрес общего сервера |
| `PLAYER_NAME` | пусто | Имя игрока, подписывает созданные объекты |
| `ANTHROPIC_API_KEY` | пусто | Включает генерацию через Claude API |
| `ANTHROPIC_MODEL` | `claude-opus-5-5` | Модель для генерации |
| `GENERATOR` | `auto` | `auto`, `anthropic`, `sampling` или `none` |

## Протокол мира

MCP-сервер не хранит мир, он только передаёт команды. Сообщения идут по WebSocket в JSON: запрос `{"id", "cmd", "args"}`, ответ `{"id", "ok", "result"}` или `{"id", "ok": false, "error"}`. Команды: `world_info`, `create` (положить объект в инвентарь и, если надо, поставить), `update`, `get_spec`, `area`, `inventory`, `list`, `move`, `remove`, `next_request` (следующая просьба игрока, ответ на вопрос или `null`), `reply`, `ask`, `progress`, `set_physics` (физика мира).

Мир держит сама игра, и строить в нём может только его создатель со своим агентом. Когда во втором релизе появятся гости, они будут только играть в мире, а команды строительства останутся у создателя.
